# feature-log skill

## 功能

- 记录 draw-web 项目所有功能点到 `docs/feature.md`
- 用于需求预审时检查新增字段/功能是否覆盖完整
- 按功能维度输出表格，以触点位置（而非组件文件夹）为索引，包括：
  - `#`：序号
  - 触点位置：功能入口/模块名称，精确到交互层级，如 `场景市场-列表`、`场景工具-参数面板`
  - 端：`创作端` / `模型端` / `管理后台`
  - 页面/Tab：`→` 串联路径，如 `首页 → 场景市场`、`个人中心 → 我的作品 → 场景`
  - 说明：一句话描述核心功能，必要时标注版本号如 `（V3.7.1）`
- 覆盖路由页面、页面内 Tab、弹窗/浮层、固定挂件、嵌套设置页等

## 触发方式

- 用户说「保存该功能为 skill」「feature-log skill」「记录功能点」「保存功能清单」等
- 或自动记录最近更新的功能点

## 依赖

- `docs/feature.md` 作为数据源
- `add-new-task-type-web` skill 可用于扩展新任务类型

## 保存规则

需要顶部增加

```md

## 创作端

最新版本：V3.7.1
更新日期：2024-06-18

```

## 示例

```bash
skill: "feature-log"
```

**表格格式示例**：

| # | 触点位置 | 端 | 页面/Tab | 说明 |
|:---|:---|:---|:---|:---|
| 1 | 场景市场-列表 | 创作端 | 首页 → 场景市场 | 卡片列表，排序：推荐/热度/最新/成功率 |
| 2 | 场景市场-卡片 | 创作端 | 场景市场 → 场景卡片 | 展示成功率标签（V3.7.1） |
| 3 | 场景详情 | 创作端 | 场景市场 → 点击进入 | 场景详情页（V3.7.1） |
| 4 | 场景工具-选择列表 | 创作端 | 场景工具面板 → 选择场景 | 弹窗/列表形式选场景（V3.7.1） |
| 5 | 场景工具-参数面板 | 创作端 | 场景工具面板 → 右侧 375px | 复合节点开关、跳过节点、参数调节 |

**保存说明**：功能清单已按最新规则（以触点位置为索引，区分创作端/模型端/管理后台）重新扫描并保存至 `docs/feature.md`。后续需求预审时可直接引用此表检查新增功能覆盖完整。
